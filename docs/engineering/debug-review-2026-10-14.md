# Debug review: 2026-10-14

This review used local fixtures and covered folder loading, preview selection and streaming, metadata operations, dialog shortcuts, and the existing workspace regression suite. It is not a complete audit or live-provider certification. No existing remote object was modified.

## Confirmed fixes

| Bug                                                                                                               | Result                                                                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Text beginning `ID3` or `BMP` incorrectly opened an audio/image viewer.                                           | ID3 and bitmap detection now checks binary header structure. Regression fixtures include the previously misclassified ASCII strings and actual binary headers.                                                                                                                                                                                              |
| Metadata changes did not reload a public preview because its URL stayed identical.                                | Public preview URLs include an ephemeral revision parameter after metadata changes. Sharing URLs remain canonical, and existing query parameters and escaped keys are preserved.                                                                                                                                                                            |
| Known text extensions bypassed the 5 MiB limit and could load an arbitrarily large object into the editor.        | Every text preview checks listed size, response size, and actual streamed bytes. Unknown or dishonest Content-Length cannot bypass the reader limit.                                                                                                                                                                                                        |
| Invalid UTF-8 after a valid-looking header was silently replaced and could be saved as corrupted text.            | The complete bounded text read uses strict UTF-8 decoding; invalid files remain downloadable but cannot be edited through this viewer.                                                                                                                                                                                                                      |
| Failed probe/text HTTP responses left their stream open.                                                          | Failed, oversized, and abandoned reads cancel their bodies. Text reads no longer use an unbounded fallback.                                                                                                                                                                                                                                                 |
| File-list shortcuts could run behind Settings, preview, or metadata dialogs.                                      | Custom dialogs expose their dialog role. Background shortcut handlers ignore both requested lazy dialogs and visible dialogs, plus already-handled editor events. Hidden dialogs do not block shortcuts. The command palette can still be closed with its own shortcut. A blocked refresh also prevents the browser fallback from reloading an open editor. |
| Private media seeks adopted the latest object ETag on every request, allowing playback to mix object generations. | A session pins its first ETag and size. Changed objects return 412 and cancel stale shared reads. Reopening gets a fresh session even if a thumbnail retains an old lease.                                                                                                                                                                                  |
| Missing object ETags silently removed the GetObject condition.                                                    | Private previews reject missing ETags or invalid sizes before starting a body read.                                                                                                                                                                                                                                                                         |

## Validation

- Frontend formatting, typecheck, and 355 tests passed. Production static export passed.
- Rust formatting, Clippy with warnings denied, and all 479 workspace tests passed. Seven existing tests and one documentation test were ignored.
- The production macOS app and DMG were rebuilt with updater artifacts disabled. `/Applications/r2.app` was replaced after normal quit; file manifests and the local ad-hoc signature were verified, with account data preserved.
- Native testing reproduced the original shortcut problem: Cmd+A selected four files behind Settings, and Cmd+U opened Upload. It also exposed a lazy-loading timing gap in the first guard. In the final installed app, the fast Settings → Cmd+A → Cmd+U → Cmd+R sequence neither selected files nor opened Upload or reloaded the dialog. File selection still worked after closing Settings. A loading command palette blocked Cmd+U and still closed with Cmd+K. No uploads, metadata saves, or preference changes were performed.
- Preview detector, byte-limit, UTF-8, stream-cleanup, and media-generation checks used automated local fixtures; this run did not perform live-provider writes or native media-codec acceptance.
- The two new Rust SDK fixtures failed against the original implementation: a changed-object seek returned 206 instead of 412, and a missing-ETag object started an unconditional read. These fixtures exercise the loopback HTTP service and authenticated SDK requests rather than only helper functions.
- The initial sandbox Rust run could not bind fixture sockets; that environment failure was resolved by running the local suite with socket permission.

The file detector remains a conservative subset of libmagic, and legacy text encodings are not supported. All text previews now have a 5 MiB limit. Live R2 writes and live AWS S3, MinIO, and RustFS behavior were not verified. Ignored platform and documentation tests remain outside acceptance.
